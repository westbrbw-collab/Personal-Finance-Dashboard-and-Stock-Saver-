# Personal Finance Dashboard & Stock Screener

## Overview
An end-to-end stock screening tool using Python, SQL, Excel DCF modeling, and Machine Learning.

## Tech Stack
- Python (yfinance, pandas, scikit-learn, matplotlib)
- SQLite
- Excel
- GitHub

## Stocks Covered
AAPL, MSFT, GOOGL, META, AMZN, NFLX, CRM, ADBE, INTC, NVDA

## Project Phases
- Phase 1: Setup
- Phase 2: Data Pipeline
- Phase 3: Excel Financial Model
- Phase 4: ML Screener
- Phase 5: Polish & Presentation
